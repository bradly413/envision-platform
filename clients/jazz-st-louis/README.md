# Jazz St. Louis

Envision client demo. The live site is [jazzsite.demos.bradlyrobert.com](https://jazzsite.demos.bradlyrobert.com), served by the Vercel project `jazz-stl-site`.

That project still deploys `bradly413/bradlyrobert` branch `cursor/jazz-st-louis-demo-2dc4` ([pull request #1](https://github.com/bradly413/bradlyrobert/pull/1)). The files in this folder are that demo: `src/jazz`, `public/jazz-site`, and the Jazz docs. `app-routes.diff` is the marketing-site route wiring (`/jazz`, `/jazz/plan`, `/jazz/site`).

`jazz-stl-hub` is paused. `jazz-stl-plan` has no active production deployment.
